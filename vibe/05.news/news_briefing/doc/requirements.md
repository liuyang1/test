# CCTV 新闻联播每日视频简报生成器

## 项目概述

自动获取 CCTV 新闻联播的文稿和视频，生成 ≤3 分钟的竖版短视频简报，配合 TTS 配音和硬字幕，适合手机端快速消费。

## 需求详情

### 1. 数据源
- 来源：央视网 (cctv.com) 新闻联播栏目
- 获取内容：每期完整文字稿 + 视频（m3u8 流下载）
- **文章标题提取**：从 `<a title="">` 属性获取准确标题，清理 `[视频]`/`【】` 前缀
- **跳过完整版**：自动过滤30分钟整期视频，只保留单条新闻视频
- **索引对齐**：`article[i]` 的文稿、标题、视频严格一一对应，确保 LLM 输出的索引能精确匹配到正确的视频片段

### 2. 文稿处理
- LLM 摘要，输出带文章索引的段落列表
- 每条摘要对应原始文章编号，实现音视频内容精确对应
- 同时输出每条新闻的简短标题（用于进度条下方显示）
- 模块化设计，当前使用 kiro-cli，可替换为其他 LLM API

### 3. 语音生成 (TTS)
- 方案：edge-tts（微软 Edge 在线 TTS）
- 语速：+35%（约 1.5x），营造高效信息消费感
- **分段生成**：每个摘要段落独立生成 TTS，获取精确时长
- **开场音效**：从新闻联播片头截取8秒作为开场引导音

### 4. 两种视频风格

#### 风格A：TTS 配音版（原有）
- 音视频内容精确对应，视频 1.5x 加速
- 三种布局：fit_top / triple / blur_full
- **所有布局统一**：顶部标题"新闻联播2分钟"+日期、底部进度条+当前新闻标题
- 进度条是真正的时间进度条，随视频播放时间线性推进（0%→100%）
- 进度条下方显示当前新闻编号和标题（如"1/8 春季农业会议"）
- blur_full 布局中视频位置上移 25%，为底部平台 UI 留空间
- 字幕位置相应上移
- 标题/字幕/进度条字体大小整体协调设计

#### 风格B：图片卡片版（新增）
- 不使用 TTS，配新闻联播原始音频作为 BGM（低音量背景）+ 开场音效
- **Pillow 排版引擎**渲染卡片图片，精确控制字体、颜色、位置
- 每条新闻生成图片卡片，卡片合成为视频
- **左对齐信息流排版**（非居中字幕风格），类似新闻 app 卡片
- 正文不截断：一页放不下自动分页，分页时标题栏和进度条保持不变
- 卡片排版：顶部标题+日期 → 新闻编号+标题 → 左对齐正文 → 底部时间进度条
- 进度条下方无文字（避免冗余）
- 每页停留时间：按正文字数估算阅读时间
- 背景：从原视频截取模糊图，新闻风格深色

### 5. 字幕（风格A）
- 类型：硬字幕（ASS 格式烧录）
- 字体大小：54-58pt，大字体适配手机阅读
- **绝对像素定位**：使用 ASS `\pos(x,y)` + `\an8` 指定精确坐标，彻底绕过 libass 碰撞检测，字幕位置永远固定不跳动
- 长文本（>14字）从中间标点处断开为上下两行，短文本单行显示在下行位置
- 每行最多 12 个中文字，确保不溢出屏幕
- 分行保护：拆分后两边至少 3 个字，避免标点孤行
- 格式化在 ASS 层统一处理（SRT 只存纯文本）
- 三种风格预设：`default`（描边白字）、`news`（半透明背景条）、`minimal`（粗描边）
- 三种布局模式一次性生成，方便对比选择：
  - `fit_top`：原视频放上方，模糊背景填充
  - `triple`：3x1 重复布局填满竖屏
  - `blur_full`：模糊背景全屏 + 原视频居中叠加
- 模糊背景：从原始视频提取帧，高斯模糊 + 降亮处理
- 纯 CPU 处理（ffmpeg），无 GPU 依赖

### 5. 字幕
- 类型：硬字幕（ASS 格式烧录）
- 字体大小：54-58pt，大字体适配手机阅读
- **绝对像素定位**：使用 ASS `\pos(x,y)` + `\an8` 指定精确坐标，彻底绕过 libass 碰撞检测，字幕位置永远固定不跳动
- 长文本（>14字）从中间标点处断开为上下两行，短文本单行显示在下行位置
- 每行最多 12 个中文字，确保不溢出屏幕
- 分行保护：拆分后两边至少 3 个字，避免标点孤行
- 格式化在 ASS 层统一处理（SRT 只存纯文本）
- 三种风格预设：`default`（描边白字）、`news`（半透明背景条）、`minimal`（粗描边）

### 6. 输出物
- **视频文件**：风格A（fit_top/triple/blur_full）+ 风格B（cards）
- **文字稿**：格式化的摘要文稿（带标题、日期、编号），可直接用于其他平台发布
- **首图**：每种方案生成封面图，"新闻联播2分钟"+日期居中大字显示，模糊背景

### 7. 水印
- 右上角硬编码水印，默认文本 "YANG"
- 可在 config.py 中自定义 `WATERMARK_TEXT`
- 半透明，全程显示

### 7. 输出规格
- 画面：竖版 720x1280 (9:16)
- 格式：MP4 (H.264 + AAC)
- 时长：≤ 3 分钟
- 一次生成 3 种布局版本

### 8. 运行方式
- 本地 Python 脚本，手动触发
- `--test` 模式独立验证各模块

### 9. 技术约束
- 纯 CPU、免费方案
- 模块化设计，各组件可独立替换和测试

## 技术方案

### 模块划分

```
news_briefing/
├── main.py              # 主入口 + 测试入口
├── config.py            # 配置（布局/字幕风格/水印/语速）
├── scraper.py           # 央视网抓取（文稿 + 视频URL）
├── downloader.py        # m3u8 视频下载
├── summarizer.py        # LLM 文稿摘要（带文章索引）
├── tts.py               # TTS 语音 + 智能分词字幕
├── video_editor.py      # 视频剪辑 + 模糊背景 + 字幕 + 水印
└── requirements.txt
```

### 处理流程

```
1. scraper     → 获取文稿 + 视频 URL（带文章索引）
2. downloader  → 下载全部视频
3. summarizer  → LLM 摘要，输出 [{"index": 2, "text": "..."}, ...]
4. tts         → 分段生成 TTS（每段独立），精确段落时长 + 固定两行字幕
5. video_editor→ 按索引+精确时长匹配原视频 → 1.5x加速 + 模糊背景 + 字幕 + 水印
                 → 一次性输出 3 种布局
```

### 使用方式

```bash
# 完整运行（3种布局）
python3 main.py --date 20260320

# 指定布局
python3 main.py --date 20260320 --layout fit_top blur_full

# 指定字幕风格
python3 main.py --date 20260320 --subtitle-style minimal

# 模块测试
python3 main.py --test
```

### 可测试性

每个模块均可独立测试：
- `python3 tts.py` → 智能分词测试 + TTS 生成测试
- `python3 video_editor.py` → 字幕烧录测试 + 布局测试 + 模糊背景测试
- `python3 scraper.py` → 抓取测试
- `python3 main.py --test` → 全部模块测试（含分行逻辑验证+截帧目视检查）

测试产物位于 `temp/test/`：
- `test_subtitle_news.mp4` - 字幕烧录测试视频
- `test_frame_*.jpg` - 字幕截帧（目视检查无异常字符、位置固定）
- `test_layout_*.mp4` - 3种布局测试视频（含1.5x倍速）

### 测试覆盖的边界情况
- 短文本（≤14字）不拆分，避免标点孤行
- 拆分后两边至少3字，防止"。"单独成行
- ASS `\pos` 绝对定位，防止 libass 碰撞检测导致位置跳动
- 截帧自动生成，便于目视验证无 `\u3000` 等异常字符
