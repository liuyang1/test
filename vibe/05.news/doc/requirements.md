# CCTV 新闻联播每日视频简报生成器

## 项目概述

自动获取 CCTV 新闻联播的文稿和视频，生成一个 ≤3 分钟的竖版短视频简报，配合 TTS 配音和硬字幕，适合手机端快速消费。

## 需求详情

### 1. 数据源

- 来源：央视网 (cctv.com) 新闻联播栏目
- 获取内容：
  - 每期完整文字稿
  - 每期视频（通过解析 m3u8 流下载）
- 数据性质：公开信息

### 2. 文稿处理

- 将完整文稿（约30分钟内容）摘要/简化为适合3分钟配音的精简文稿
- 摘要方案：通过 LLM 生成（当前阶段使用 kiro-cli 命令调用）
- 模块化设计，方便后续迁移到其他 LLM API

### 3. 语音生成 (TTS)

- 基于精简文稿生成中文配音
- 方案：edge-tts（微软 Edge 在线 TTS，免费，中文质量好）
- 可接受类似的免费/灰色地带方案
- 配音时长控制在 ≤3 分钟

### 4. 视频生成

- 画面内容：从原始新闻联播视频中截取关键帧/片段作为背景画面（方案A）
- 视频与 TTS 配音对齐
- 纯 CPU 处理（ffmpeg），无 GPU 依赖
- 便于部署在任意环境

### 5. 字幕

- 类型：硬字幕（烧录到视频中）
- 来源：精简文稿内容
- 与 TTS 配音同步

### 6. 输出规格

- 画面方向：竖版（9:16）适配手机
- 分辨率：主流手机适配即可（如 720x1280）
- 格式：MP4
- 时长：≤ 3 分钟

### 7. 运行方式

- 形态：本地脚本，手动触发
- 无需定时任务
- 无需错误通知机制

### 8. 技术约束

- 纯 CPU 运行
- 免费方案优先（可接受免费试用的云端服务）
- 不使用付费 API
- 模块化设计，各组件可独立替换

## 技术方案

### 技术栈

- 语言：Python
- 视频处理：ffmpeg (subprocess 调用)
- TTS：edge-tts
- 网页抓取：requests + BeautifulSoup
- 视频下载：m3u8 解析 + ffmpeg
- 文稿摘要：kiro-cli（当前），模块化接口预留 LLM 替换

### 模块划分

```
news_briefing/
├── main.py              # 主入口，串联各模块
├── scraper.py           # 央视网数据抓取（文稿 + 视频URL）
├── downloader.py        # 视频下载（m3u8 解析）
├── summarizer.py        # 文稿摘要（LLM 接口）
├── tts.py               # TTS 语音生成
├── video_editor.py      # 视频剪辑 + 字幕合成
├── config.py            # 配置参数
└── requirements.txt     # Python 依赖
```

### 处理流程

```
1. scraper     → 获取当日新闻联播文稿 + 视频 m3u8 地址
2. downloader  → 下载完整视频
3. summarizer  → 文稿摘要为 ≤3 分钟配音稿
4. tts         → 精简文稿 → TTS 生成配音音频
5. video_editor→ 从原视频提取关键片段 + TTS 音频 + 硬字幕 → 输出竖版短视频
```
