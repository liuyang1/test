## 数据缓存方案

SCF 的 `/tmp` 目录在实例回收后丢失，且不同实例间不共享，因此不能用于跨请求缓存。

| 选项 | 成本 | 说明 | 决策 |
|------|------|------|------|
| 腾讯云 COS（对象存储） | 免费额度 50GB + 200万次读写/月 | 定时任务写缓存 JSON，用户请求读缓存，内网访问速度快 | ✅ 采用 |
| CFS（文件存储） | 有免费额度 | 可挂载为本地目录，代码改动最小 | 备选 |
| 云数据库 | 付费 | 过重 | 不考虑 |

部署架构：

```
定时触发器（每天15:30）→ cron 云函数 → 拉数据+预计算指标 → 写入 COS
用户消息 → API网关 → index 云函数 → 从 COS 读缓存 → 返回结果（毫秒级）
```

## 微信服务号企业资质要求

认证服务号需要以下资质之一：
- **企业**：营业执照
- **个体工商户**：营业执照
- **政府/事业单位**：组织机构代码证
- **其他组织**：组织机构代码证

认证流程：提交资质 → 腾讯审核 → 第三方审计公司电话确认 → 认证费 300 元/年

个人开发者替代方案：注册个体工商户（成本低，部分地区可线上办理），即可申请服务号认证。
