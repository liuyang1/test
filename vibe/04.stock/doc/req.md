# AI 炒股助手 - 需求文档

## 1. 核心功能

### 1.1 选股荐股
- 基于市场数据、技术指标、基本面分析进行智能选股
- 根据用户偏好（题材、行业、风格）推荐个股
- 支持多种选股策略（趋势、价值、动量等）

### 1.2 跟踪分析
- 实时跟踪用户持仓及关注股票
- 技术面分析（K线形态、均线、MACD、RSI 等）
- 基本面分析（财报、估值、行业对比）
- 资金流向与市场情绪监控

### 1.3 买卖点建议
- 基于技术指标给出买入/卖出信号
- 设定止盈止损建议
- 结合大盘走势给出操作时机建议

### 1.4 用户画像与个性化
- 记录用户偏好：
  - 关注题材/行业板块
  - 风险偏好（保守/稳健/激进）
  - 投资周期（短线/中线/长线）
  - 资金规模
- 根据用户画像定制推荐策略
- 学习用户历史操作，持续优化建议

## 2. 设计决策

| 问题 | 决策 |
|------|------|
| 数据源 | 默认 A 股，按需支持港股、美股 |
| 回测系统 | 不做，复杂度超出范围 |
| 模拟盘 | 不做 |
| 通知机制 | 微信推送 |
| 多用户架构 | 需要，用户数据隔离 |
| 合规风控 | 待定 |
| AI 模型选型 | 当前阶段：规则引擎（技术指标信号）；后续可演进至 ML/LLM |
| 前端交互 | 微信公众号/小程序 |
| 数据采集频率 | 当前阶段：日线级别 |
| 规则自定义 | 支持，通过 LLM 语义理解将自然语言转为规则参数 |

## 3. E2E 主流程

1. **用户注册/登录** → 通过微信公众号/小程序，建立用户画像
2. **对话交互** → 用户用自然语言描述选股需求和偏好
3. **LLM 意图解析** → 将自然语言转换为规则引擎可执行的参数
4. **数据采集** → 每日拉取 A 股行情、K线、财务数据
5. **规则引擎选股** → 根据解析后的规则 + 用户画像，筛选候选股票
6. **荐股推送** → 将筛选结果通过微信推送给用户
7. **持仓跟踪** → 用户标记持仓/关注后，系统持续监控
8. **买卖信号** → 触发止盈/止损/技术信号时，微信通知用户
9. **记录反馈** → 记录推荐历史和用户操作，用于后续优化

## 4. 系统架构（概要）

```
用户（微信） ↔ LLM（意图解析/对话） ↔ 规则引擎（选股/择时） ↔ 数据层（行情/财务）
```

- LLM 层：负责自然语言理解，不做预测，只做意图→规则的翻译
- 规则引擎：执行技术指标计算和信号判断，可控可解释
- 数据层：日线级别行情数据采集与存储
